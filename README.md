# 🤖 Rule-Based AI Chatbot

## Welcome

Welcome to the Rule-Based AI Chatbot project!

This project was developed as part of the **Artificial Intelligence Industrial Training Program (Batch 2026)** powered by **DecodeLabs**. It demonstrates how the core principles of Artificial Intelligence can be implemented using simple programming logic before moving on to advanced concepts like Machine Learning and Deep Learning.

The chatbot is designed to simulate a basic human conversation by responding to predefined user inputs. Instead of learning from data, it follows a set of carefully written rules using Python's conditional statements.

---

## About the Project

Artificial Intelligence is not limited to machine learning models and neural networks. One of the earliest and most fundamental approaches to AI is a **Rule-Based System**, where a computer makes decisions based on predefined conditions.

This project implements a chatbot that continuously interacts with users, understands specific commands, and provides appropriate responses using logical decision-making.

The chatbot remains active until the user chooses to end the conversation, making it a simple yet interactive example of conversational AI.

## How It Works

1. The chatbot welcomes the user.
2. It waits for the user to enter a command.
3. The input is converted into lowercase to avoid case-sensitive comparisons.
4. The chatbot compares the input with predefined rules.
5. If a matching rule is found, it displays the corresponding response.
6. If the command is unknown, it politely informs the user.
7. The chatbot continues running until the user types an exit command.
